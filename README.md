# hdconfigure_tools

An easy-to-use, lightweight package manager built exclusively for **Debian Stable**. Designed for simplicity and reliability, `hdconfigure_tools` streamlines environment setup and tool management without unnecessary bloat or cross-distribution overhead.

## Quick Install

Run the following command in your terminal to clone, install, and clean up automatically:

```sh
if git clone [https://github.com/hdconfigure/hdconfigure_tools](https://github.com/hdconfigure/hdconfigure_tools) /tmp/hdconfigure_tools; then if sh /tmp/hdconfigure_tools/install.sh; then rm -rf /tmp/hdconfigure_tools; fi; fi
